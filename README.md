# TengokuFirst profile

Статичный сайт для GitHub Pages. Откройте `index.html` локально или включите Pages для ветки репозитория.

## Изображения

Положите пользовательские изображения в `assets/images/`. Для главного аватара используйте имя `avatar.jpg`. Если файла нет, появится текстовый fallback `TF`. Фон можно подключить в `styles.css`, заменив фон `body` на `url('assets/images/background.jpg')`.
